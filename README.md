# Overview

Cube Dash is an open-source rhythm platformer inspired by precision-based games.

The project is built from scratch in Rust using the Bevy game engine.

The main goals are:

- High-performance gameplay
- Deterministic physics
- Modular architecture
- Custom level creation
- Reliable collision handling
- Automated testing

Cube Dash is designed to be lightweight, extensible and easy to modify.
